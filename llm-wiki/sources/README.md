# Raw sources

This folder holds outside material for the wiki to ingest: PDFs, transcripts,
articles, datasets and notes. Files already in this repository are not copied
here. The wiki cites them in place.

- Name files `YYYY-MM-DD-short-slug.ext`, using the date they were added.
- Once a file is added, never edit or rename it. A revised version is a new
  file. `lint.py` fails if an ingested file changes.
- Each file gets a page in `../wiki/sources/`. See `../CLAUDE.md`, "Ingest".

This README is not a source.
