Based on a summary of "Unlock AI Mastery with ASDSTE-100" by Felix Reed (AI News & Chips). Examples below are written for this page, not model output.

1 · ASD-STE100

Clear text, "about 80%"

ASD-STE100 is Simplified Technical English. Pick a level to see the same instruction rewritten.

2 · DIAGRAMS

Ask for a picture, not paragraphs

The format request is the trick. Name the format: diagram, table, page or script.
