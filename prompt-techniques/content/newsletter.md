# Newsletter: Four prompt tricks, one from aerospace

*Subject line options:* "The aerospace trick for better prompts" / "Stop asking AI for paragraphs"

A short video by Felix Reed (AI News & Chips) lists four ways to change how you ask. I haven't seen the video itself, only a timestamped summary, so I'm giving you the ideas and my own examples.

## 1. Ask for ASD-STE100
ASD-STE100 is Simplified Technical English, a controlled language maintained by ASD, the aerospace and defence association. It has a set of writing rules and an approved word list. The goal is text that a non-native reader can't misread.

The video's tweak: ask the AI to follow it "about 80% of the way". Full strictness reads stiff. Eighty percent keeps the clarity and drops the robot.

Example (written by me, not model output):
- Before: "Prior to commencing installation, it is imperative that power be disconnected."
- About 80%: "Before you start, make sure the power is off."
- Strict: "Disconnect the power."

## 2. Ask for diagrams
If the answer is a process, a flow or a set of relationships, say so: "Show this as a diagram." You can read it faster than three paragraphs.

## 3. Ask for an interactive page
Ask for HTML, CSS and JavaScript. The video's example is an SIP (systematic investment plan) calculator with sliders and a compounding graph. I built a small one in the companion explainer. It's a demo and not financial advice.

## 4. Ask for an explainer video
Have the AI write the script and scene notes, then pair it with a text-to-speech voice such as ElevenLabs. Budget time to review the script yourself.

Add "Follow ASD-STE100 about 80% of the way" to one prompt. Compare the two answers. Reply and tell me which you prefer.
