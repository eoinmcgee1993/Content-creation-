# Explainer script (~60 s)

Written in the plain style it describes. Roughly 150 spoken words.

| Time | Visual | Narration |
|---|---|---|
| 0–5 s | Manual page, one sentence highlighted | Aerospace manuals must be read once and understood. |
| 5–15 s | Long sentence collapses into a short one | They use a standard called ASD-STE100. Short sentences. Simple words. |
| 15–25 s | Prompt box: "Follow ASD-STE100 about 80% of the way" | Put it in your prompt. Say "about 80%". The text stays clear and still sounds human. |
| 25–35 s | Paragraph morphs into a flow diagram | Second: ask for a diagram. A process is easier to see than to read. |
| 35–47 s | Sliders move, chart curve grows | Third: ask for a web page. One prompt can give you a calculator with sliders and a chart. |
| 47–57 s | Waveform under animated scene | Fourth: ask for an explainer script. Add a text-to-speech voice. |
| 57–60 s | Title card | Try the first one today. Credit: Felix Reed. |

Production: use the repo's `hyperframes` skill, or ElevenLabs for narration, only after the script is approved. No voice or video has been generated yet.
