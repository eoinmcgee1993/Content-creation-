# Fact-check

Checked 2026-10-14. "Video" claims come from a pasted summary of the video, not
from watching it.

| Claim | Status | Notes |
|---|---|---|
| The video lists four techniques: STE, diagrams, interactive web pages, explainer videos with TTS | From summary | Timestamps given: 00:08, 00:41, 00:48, 01:02. |
| Adding "follow ASD-STE100 about 80% of the way" keeps output clear without sounding robotic | Video's advice, untested here | A prompting tip, not a measured result. `site/` shows illustrative examples written for this project, not model output. |
| ASD-STE100 is a controlled language for technical writing, owned by ASD in Brussels | Verified | [asd-ste100.org](https://asd-ste100.org/about_STE.html), [Wikipedia](https://en.wikipedia.org/wiki/Simplified_Technical_English). |
| Current issue is Issue 9, January 2025 | Verified (one search) | A Wikipedia mirror still showed Issue 8 (April 2021) as current, so it is stale. Re-check at publish time. |
| It has a set of writing rules plus a controlled dictionary of roughly 900 approved words | Verified (Wikipedia) | Wikipedia gives 53 writing rules. Older issues are commonly cited with a different count, so say "dozens of rules" instead of a number. |
| Max 20 words in procedural sentences, 25 in descriptive ones | Unverified | Seen in a third-party paraphrase only. Check the official, free specification before quoting. |
| The specification is free of charge since Issue 6 (2013) | Verified (Wikipedia, one source) | |
| The video's example is an SIP calculator with sliders, compounding graph and animation | From summary | `site/` builds its own calculator. It is a demo, not financial advice. |
| "3Blue1Brown-style" explainers with 11Labs narration | From summary | The summary writes "11Labs"; the product is ElevenLabs. Not tested here. |
| STE came from the aerospace industry | Partly verified | The standard is made by the aerospace and defence association ASD. Origins in the 1980s are not checked here, so the content avoids dates. |

## Claims the content deliberately avoids
- Any percentage improvement or "proven" result for these techniques.
- Specific rule numbers.
- Any statement that STE makes AI output more accurate. It aims at clarity for readers.
