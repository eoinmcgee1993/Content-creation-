# DEGEN DIARIES

Twice-weekly newspaper for the internet age.

## Editions
- Tuesday Edition
- Friday Edition

## Sections
- MONEY: crypto, markets, business
- MACHINE: AI, technology, software
- SPORT: football, combat, racing, GAA and the strange bits
- CULTURE: music, film, books, internet culture
- THE RABBIT HOLE: weird, obscure, fascinating
- THE DOSSIER: one deep dive per issue

## Editorial engine
Gmail/newsletters -> ingestion -> source extraction -> dedupe -> story scoring -> original rewrite -> fact/source QA -> page composition -> PDF/web -> subscriber email.

The system must preserve source attribution and never fabricate facts, quotes or statistics.

## Cadence
Build automatically twice weekly. Human approval remains the final publish gate.
