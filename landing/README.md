# Lead-Capture Landing Page

Self-hosted Flask landing page for the B2B audit offer. Captures emails
(stored locally — you own the list) and delivers a **freebie**: an
instant sanitized sample audit report generated by the in-repo `audits`
toolkit, plus lead details for personalized follow-up.

## Run locally

```bash
pip install -r landing/requirements.txt
python -m landing.app                 # http://localhost:5000
# or: PORT=8080 python -m landing.app
```

The sample report (PDF + Markdown) is generated into `landing/static/`
on startup from `audits/sample_data/`.

## How it works

- `GET /` — landing page with the capture form (email required;
  website + monthly ad spend optional).
- `POST /subscribe` — validates the email server-side, appends the lead
  to `landing/leads.csv`, redirects to `/thanks`.
- `/thanks` — instant download links for the sample report.
- `/healthz` — JSON health check for deployment probes.

## Your leads

Captured leads are appended to `landing/leads.csv` with columns:
`timestamp, email, website, monthly_ad_spend, source`. This file is
**git-ignored** — it contains personal data and must never be committed.
Override the location with the `LEADS_PATH` environment variable.

To follow up, import `leads.csv` into your email tool / CRM, or wire
`POST /subscribe` to an email platform later.

## Deploy

Any host that runs a Flask/WSGI app works (Render, Railway, Fly, a VM
with gunicorn). Example:

```bash
pip install gunicorn
gunicorn "landing.app:app" --bind 0.0.0.0:$PORT
```

Run from the repository root so the `audits` package is importable.
